# Dashboard public assets

Drop the mascot PNGs here (transparent background). The app references them by
these exact filenames and hides any that are missing:

- `mascot.png` — main bird, front-facing (used in the header + About page)
- `mascot-wave.png` — waving pose (About page)
- `mascot-thumb.png` — thumbs-up pose (shown on a successful nomination)

Anything in this folder is served at the site root, e.g. `public/mascot.png`
is available at `/mascot.png`.
